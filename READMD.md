# Open Source Collection

A curated repository for managing third-party open source projects with Git submodules.

## Goals

- Keep third-party projects organized
- Preserve upstream history
- Support reproducible checkout
- Provide one-command bootstrap and update workflows
- Maintain project inventory documentation

## Repository Layout

```text
.
├── docs/                  # Project documentation
├── scripts/               # Maintenance scripts
